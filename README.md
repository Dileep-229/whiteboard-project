# Collaborative Whiteboard Application

A real-time collaborative whiteboard application that allows multiple users to join a room, draw together, chat, add sticky notes, and collaborate seamlessly using Socket.IO.

## Features

- Real-time collaborative drawing
- Room creation and joining with password protection
- Live user tracking
- Pen, Eraser, Rectangle, Circle, and Line tools
- Undo and Redo functionality
- Real-time chat system
- Sticky notes support
- Live cursor tracking
- Whiteboard image download
- Duplicate username prevention

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- Socket.IO
